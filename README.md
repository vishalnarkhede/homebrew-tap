# Homebrew Tap

Personal Homebrew tap for [vishalnarkhede](https://github.com/vishalnarkhede)'s tools.

## Install

```bash
brew install --cask vishalnarkhede/tap/bracepaste
```

| Cask | Description |
|---|---|
| [`bracepaste`](https://github.com/vishalnarkhede/BracePaste) | Format JSON and SQL from the clipboard with a double ⌘C gesture |
